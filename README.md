# Termas Punulaf — Reservas y administración

Aplicación web de reservas para un recinto de termas (tinas, saunas y piscinas).
Funciona **íntegramente en el navegador**: no hay backend, base de datos ni servicios
externos. Todo el estado se guarda en `localStorage`.

## Requisitos

- Node.js 20 o superior
- npm

## Arranque

```bash
npm install
npm run dev
